# SmartBudget API

SmartBudget API is a layered ASP.NET Core Web API developed for managing personal budgets.

## Features

- User Authentication (JWT)
- Expense Management
- Income Management
- Category Management
- AI Budget Analysis
- Entity Framework Core
- SQL Server

## Technologies

- ASP.NET Core
- C#
- Entity Framework Core
- SQL Server
- AutoMapper
- FluentValidation
- JWT Authentication
- OpenAI API

## Architecture

- API
- Business
- DataAccess
- DTO
- Entities
- Core
